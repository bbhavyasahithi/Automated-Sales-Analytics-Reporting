# Automated Sales Analytics & Reporting

## Project Overview

This project is an automated sales analytics and reporting solution developed using **Google Sheets and Google Apps Script**. The objective was to transform raw sales data into clean, analysis-ready data and automate the complete reporting process.

The solution includes data cleaning, KPI calculation, interactive filtering, dashboard generation, report creation, and scheduled email distribution. This reduced manual reporting effort and provided stakeholders with regularly refreshed sales performance information.

## Objectives

* Automate the preparation of raw sales data.
* Clean and standardize data for reporting.
* Build KPI-based sales dashboards.
* Enable filter-based business analysis.
* Automate report generation and email distribution.
* Reduce repetitive manual reporting activities.

## Workflow

```text
Raw Sales Data
      ↓
Data Cleaning & Transformation
      ↓
Analytics-Ready Dataset
      ↓
KPI Calculation
      ↓
Interactive Filters
      ↓
Dashboard & Charts
      ↓
Automated Reports
      ↓
Scheduled Email Distribution
```

## Key Features

* Automated ETL workflow using Google Apps Script.
* Duplicate removal and data standardization.
* Data type conversion and validation.
* Dynamic filters and data validation.
* Automated KPI calculations.
* Interactive sales dashboards.
* Region and product-category analysis.
* Filter-based report generation.
* Automated stakeholder email reporting.
* Scheduled Apps Script triggers for recurring workflows.
